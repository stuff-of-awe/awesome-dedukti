# Awesome Dedukti and Lambdapi

Dedukti is a type checker for a logical framework with rewriting; Lambdapi expands the same family of proof-development and interchange workflows. Proof translation is a separate soundness obligation.

**Status:** starter collection, initial review 2026-11-15. **Curator:** unassigned — contributions welcome. Entries are original short annotations of external sources, not endorsements or copies of their content. No tool was installed or executed for this initial list.

## Start here

- [Dedukti source](https://github.com/Deducteam/Dedukti) — Find tool versions, manuals and repository history.
- [Dedukti tutorial](https://github.com/Deducteam/Dedukti/blob/master/TUTORIAL.md) — Learn simple lambda-Pi modulo rewriting encodings and checking.
- [Lambdapi source](https://github.com/Deducteam/lambdapi) — See its proof assistant, installation and example pointers.

## First exercise (not yet execution-tested here)

Check a small logical encoding, intentionally change a rewriting rule to break a typing judgment, and record the resulting diagnostic.

## Assurance and interoperability

A checked translated derivation does not by itself establish that its source-to-framework translation preserves the original semantics; record the translation assumptions.
